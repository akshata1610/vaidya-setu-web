# Upload this version to your existing GitHub repository

This folder is version **0.3.2-web**, matching the already updated website. Its docs include PRD **3.1**, release notes and honest test evidence.

1. Open your existing repository on GitHub, at its top level.
2. Choose **Add file → Upload files**.
3. Drag the contents inside this folder into GitHub. README.md should stay at the top level. Do not upload the ZIP itself or add an extra enclosing project folder.
4. Save the commit **Fix transcription recovery and update docs for v0.3.2**. Follow any branch and pull request flow GitHub requires.
5. Check the README and lib/domain.ts show 0.3.2-web. Keep the existing live website link.

Read [the detailed guide](docs/GITHUB_UPLOAD_GUIDE.md) for screenshots-independent steps and the saved-recording retry instructions. The separate MP4 is an illustrated narrated guide, not a recording of an upload to your GitHub account.

No patient recordings, private case exports or real API keys are included. The website and GitHub are not automatically synced. Uploading these files does not automatically redeploy the existing website.
